📱 Prácticas Flutter - Unidad 1

Este repositorio reúne las prácticas y ejercicios realizados durante la primera unidad de la materia Desarrollo de Aplicaciones para Dispositivos Móviles, utilizando Flutter y Dart.

🚀 Temáticas principales trabajadas

A lo largo de las prácticas se trabajaron diferentes elementos fundamentales para la creación de interfaces y aplicaciones móviles con Flutter:

-Uso de Flutter y Dart.
-Creación de interfaces gráficas.
-Uso de StatefulWidget y State.
-Uso de Scaffold y AppBar.
-Organización de elementos mediante Column y Center.
-Uso de Card, Container, Padding y SizedBox.
-Personalización de widgets mediante TextStyle.
-Uso de colores y sombras para mejorar la interfaz.
-Creación y configuración de botones.
-Uso de ElevatedButton y ElevatedButton.icon.
-Manejo de cajas de texto mediante TextField.
-Uso de TextEditingController para obtener información.
-Realización de operaciones matemáticas.
-Validación de datos mediante condiciones if.
-Uso de operadores lógicos como &&.
-Actualización de la interfaz mediante setState().
-Manejo de alertas mediante AlertDialog y showDialog().
-Uso de imágenes almacenadas localmente con Image.asset().
-Uso de SingleChildScrollView para desplazar contenido.
-Uso de Expanded para distribuir el espacio disponible.
-Creación de formularios básicos.
-Navegación entre diferentes pantallas.
-Uso de Navigator.pushReplacement().
-Envío de información entre pantallas.
-Uso de parámetros final y required.
-Recepción de datos mediante widget.
-Uso de initState() para inicializar información.
📚 Prácticas realizadas

Durante la unidad se desarrollaron diferentes ejercicios para poner en práctica los conceptos anteriores:

-Práctica 1: Creación de una interfaz básica y uso de textos.
-Práctica 2: Creación de interfaces utilizando diferentes widgets.
-Práctica 3: Realización de operaciones matemáticas.
-Práctica 4: Uso de botones para realizar diferentes operaciones.
-Práctica 5: Inserción y visualización de imágenes.
-Práctica 6: Creación de un sistema de Login y navegación entre pantallas.

🛠️ Requisitos

Para ejecutar las prácticas se necesita:

-Flutter SDK
-Dart
-Android Studio o un entorno compatible.
-Un dispositivo Android físico o un emulador.
-Un editor de código como Visual Studio Code o Android Studio.
